# Mentalmatics

A cross-platform app for adults to train mental math at their own
pace — no accounts, no cloud requirement, no ads.

> The name is a blend of "mental math" and "mathematics".

## Features

- **General mental math** — basic to advanced arithmetic operations,
  freely selectable difficulty.
- **Real-life everyday scenarios** — e.g. unit-price comparison,
  discount calculation, tipping.
- **Computing-related math** — conversion between number bases
  (binary, octal, hexadecimal, custom base).
- **Tips & Tricks** — informative calculation techniques (e.g. the
  Trachtenberg system) and explanations.
- Timed mode or free practice — your choice.
- Optional, local progress tracking — fully switchable off.
