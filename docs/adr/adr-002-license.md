# ADR-002: License Choice

**Status:** Decided
**Date:** Planning phase

## Context

The project should be open source, among other reasons because
F-Droid prefers/requires FOSS licenses.

## Decision

**MIT license.**

## Alternatives

No other licenses were evaluated in detail — MIT was the clear
preference from the start.

## Consequences

- Maximum reusability of the code by third parties.
- F-Droid compatibility with respect to license requirements is
  satisfied.
