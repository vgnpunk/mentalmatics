# Examples

Domain examples of task types, as guidance for later implementation
(at the ticket level). Not a complete task catalog, but representative
examples per exercise area.

## General Mental Math

- Easy: `7 + 5 = ?`, `12 − 4 = ?`
- Medium: `47 + 38 = ?`, `12 × 7 = ?`
- Hard: `364 − 178 = ?`, `144 ÷ 12 = ?`, `23 × 17 = ?`

## Real-Life Everyday Scenarios

- **Unit-price comparison**: "Package A: 750 g for €2.49. Package B:
  1 kg for €3.49. Which package is cheaper per 100 g?"
- **Discount**: "An item costs €45, with a 20% discount. How much
  does it cost after the discount?"
- **Tipping**: "The bill is €38.50. How much is a 10% tip, rounded up
  to the nearest whole euro?"

## Computing-Related Math

- Quick selection: "Convert `1011₂` to decimal."
- Quick selection: "Convert `42` (decimal) to hexadecimal."
- Custom base: "Convert `17` from base 5 to base 3."

## Tips & Tricks (Example Excerpt)

- **Trachtenberg system, multiplying by 11**: For a two-digit number
  `ab`, the result is `a, (a+b), b` — e.g. `36 × 11`: `3`, `3+6=9`,
  `6` → `396`.
- **Decimal → binary conversion (explanation)**: Repeatedly divide by
  2, note the remainders in reverse order.
