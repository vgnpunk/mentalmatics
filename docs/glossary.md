# Glossary

Domain terms of the mental math app (not technical project terms like
"ADR" or "ticket" — see `CONTRIBUTING.md` for those).

- **Mental math** — calculating without aids (calculator, paper).
- **Operation type** — a single selectable arithmetic operation (e.g.
  addition, subtraction, multiplication, division, base conversion).
- **Difficulty level** — a setting that controls the number size/
  complexity of tasks.
- **Timed mode** — practice mode with a timer, goal: solve as many
  tasks as possible in the available time.
- **Free practice** — practice mode without a time limit.
- **Real-life scenario** — a task type with an everyday-life context
  (e.g. unit-price comparison, discount calculation, tipping).
- **Number base / positional numeral system** — a number system with a
  fixed base (e.g. binary, octal, decimal, hexadecimal).
- **Custom base** — a freely user-chosen, non-standard base for number
  base conversion.
- **Progress tracking** — optional local recording of practice results
  over time.
- **Tips & Tricks section** — the informative app section with
  calculation techniques and explanations.
- **Trachtenberg system** — a collection of fast mental-calculation
  techniques (example content in the Tips & Tricks section).
- **MVP** — Minimum Viable Product, the first functional version with
  core features.
